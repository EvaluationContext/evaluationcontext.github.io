Azure DevOps product icons, monochrome in the text colour, used in the docs as `:azure-<name>:`.

- `pipelines.svg` is the Azure Pipelines rocket, from [simple-icons](https://simpleicons.org) 9.21.0 (CC0 1.0; later releases dropped the Microsoft brand icons), with `fill="currentColor"` added and the `<title>` removed.

Zensical caches inlined icons in `.cache/` at the repo root; delete it after changing anything here.
